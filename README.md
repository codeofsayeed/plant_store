# 🌿 Plant Store Website

A modern, responsive, and user-friendly **Plant Store Website** built with **HTML5, CSS3, Bootstrap 5, and JavaScript**. The project focuses on creating an elegant user experience while showcasing beautiful indoor plants and useful plant care resources.

---

## 📌 Overview

The Plant Store project is a multi-page frontend website designed for plant lovers. It features a clean interface, responsive layout, plant care information, embedded educational videos, and real-time date & time updates using JavaScript.

---

## 🚀 Features

- 🌱 Responsive Design
- 🏠 Home Page
- ℹ️ About Page
- 📞 Contact Page
- 📱 Mobile-Friendly Layout
- 🎨 Bootstrap 5 Components
- 💚 Modern UI Design
- 📹 Embedded YouTube Plant Care Video
- 📅 Real-Time Date & Time Display
- 🔗 External Plant Care Guide
- ⚡ Fast and Lightweight
